# Artwork photographs

Drop the photo for each piece in here and point the `image:` field of the
matching file in `_art/` at it, e.g.:

```yaml
image: /assets/images/art/ridge-line.jpg
```

Until that file exists, the store shows a generated gradient panel with the
piece's initials instead of a broken image, so a listing can go up before its
photograph does.

**Tips**

- Shoot square-on in even daylight, no flash.
- Around 1600 px on the long edge is plenty; keep files under ~500 KB.
- `.jpg` for photographs, `.png` only if you need transparency.
- Extra detail shots go in the same folder and get listed under `gallery:`.

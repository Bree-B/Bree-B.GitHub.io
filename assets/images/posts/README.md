# Post images

Images used in blog posts live here. Reference them from a post with:

```markdown
![Alt text describing the image](/assets/images/posts/your-file.jpg)
```

Set a post's header image with the `cover:` field in its front matter:

```yaml
cover: /assets/images/posts/your-file.jpg
cover_alt: "A short description for screen readers."
```

Keep files under ~500 KB and around 1600 px on the long edge.
